## The one user

The **Bhopal Municipal Corporation officer who plans Durga visarjan** (20 October 2026) at the ghats, and decides where to send extra cleaning, aeration and water testing. Today the test results sit in 90–120 page MPPCB PDFs. This tool lines them up for that officer.

## What it gives the officer

1. A **ranked list of Bhopal's 7 immersion ghats** by a 0–100 risk score, with the reason for each rank in plain words.
2. **Every number traceable**: each reading shows its value, the CPCB limit, whether it is outside the limit, and the report file and PDF page.
3. A **one-page brief in English and Hindi** to forward, generated by code from the computed numbers (no language model, so no figure can drift), with a Copy button that copies plain text.
4. **Honest gaps**: missing readings are shown as missing, never as clean, and each ghat gets a score range and rank range that cover them.

## Run it (stdlib Python 3.10+, no network, no API keys)

1. `git clone <this repo>` and `cd` into it.
2. `python run.py` (on Windows, `py run.py` if `python` opens the Microsoft Store).
3. Open `outputs/report.html` in any browser. Use the English / हिंदी switch at the top.
4. Run the tests: `python -m unittest discover -s tests`.
5. Optional, to check the data against the original PDFs (needs `pdftotext` from poppler, and the PDFs from the hackathon repo's `tracks/02-visarjan-ghat-watch/resources/`): `python tools/verify_pdf.py PATH/TO/resources`.

## Publish on GitHub Pages

`python run.py` also writes the report to `docs/index.html`. In the repository go to **Settings > Pages**, choose **Deploy from a branch**, branch `main`, folder `/docs`, and save. The site is then at `https://<user>.github.io/<repo>/`. Re-run `python run.py` and push to update it.

## Features added for officers

- **Download PDF** (Brief section): prints only the brief, on one A4 page, in the language currently selected. Use the browser's *Save as PDF* destination.
- **Compare ghats**: pick two or three ghats and see DO, BOD and pH side by side (breach share, worst reading with page, part score), plus a plain-words line on where the scores differ. All numbers are the ones the ranking uses.
- **Before / during / after** under each trend chart: the three readings per festival with the change between them. It reports changes between measured readings only and says it does not show cause.
- **Suggested checks** on each ghat card (`ghatwatch/actions.py`): a tickable list drawn from that ghat's readings, each item citing the counts it rests on. These are the project's suggestions, not official rules; the single threshold (a parameter counts as "often outside the limit" at 50% or more of measured readings) is at the top of the file. Ticks stay in the browser.
- **Files tab**: officers can add CSV and PDF files; they stay in the browser, are never uploaded, and never feed the ranking.
  - **CSV**: validated, matched to the seven ghats and checked against the Class B limits.
  - **PDF analysis**: the page bundles pdf.js (Apache-2.0, `ghatwatch/assets/vendor/`) and reads MPPCB-style immersion tables in the browser. `ghatwatch/assets/pdf_analysis.js` places each number under the *Pre / During / After* column by its position and extracts pH, DO and BOD per site, year and festival. Each row is **Clear** (all values in their columns and physically plausible), **Partial** (a value missing) or **Check page** (impossible value or stray text). A table whose ghat name is not in the PDF's text layer is listed as "name not readable" and never assigned to a ghat. The result shows highlights, a comparison with the dashboard data, filters, and a CSV export; scanned PDFs (no text layer) are refused with an explanation because OCR is not included.
  - **Measured accuracy** (`node tools/check_pdf_reader.js PATH/TO/resources`, needs `npm install pdfjs-dist@3.11.174`): on the three original reports it recovers 103 of the 111 verified fully numeric DO/BOD/pH rows exactly, with 0 "clear" rows disagreeing with `data/bhopal_ghats_2023_2025.csv`. The other 8 are tables whose ghat name is not readable in the PDF. Uploading each full report in the browser matches 121 (2023), 118 (2024) and 95 (2025) readings to the dashboard data with 0 differences. Layouts other than these reports are untested; always confirm a value on the PDF page.

Accessibility: automated WCAG 2.0/2.1 A/AA and best-practice audit with axe-core reports no violations on the dashboard (English and Hindi) or the Files tab at desktop and phone width; every control is reachable by keyboard; reduced-motion is respected; touch targets are 44 px. A screen-reader and real-phone pass has not been done.

## How the score works

**Yardstick: CPCB Class B (outdoor organised bathing)**: DO at least 5 mg/l, BOD at most 3 mg/l, pH 6.5–8.5, read from `data/cpcb_water_quality_criteria.csv`. CPCB has no class for idol immersion; Class B is the nearest designated use for water people enter. It is a screening yardstick, not a legal finding.

For each of DO, BOD and pH, over measured readings only:

- breach rate = readings outside the limit ÷ measured readings (a reading exactly on the limit is not a breach)
- severity per reading (0–1): DO = shortfall below 5 ÷ 5; BOD = excess above 3 ÷ 9 (12 mg/l or more = 1); pH = distance outside 6.5–8.5 ÷ 1.5, capped at 1
- parameter score = 0.5 × breach rate + 0.5 × mean severity
- **risk score = 100 × mean of the three parameter scores**

**Missing data** (blank, `_`, `-`, `*`, `**`, "not sampled", or anything unexpected) is excluded from the score and shown as missing. **BDL / ND** are kept as their own status (very low, not zero, not missing); in this data they occur only in unscored tests. Missing festival-year tables are detected from the data (Bairagarh and Malikhedi have no Durga 2025 table) and counted as missing readings. The **score range** assumes every missing reading was fine (low end) or a full breach (high end); the **rank band** follows from the ranges. A **Durga-only rank** is a cross-check.

**Sensitivity:** re-ranked under 6 weightings (shipped; breach rate only; severity only; DO only; BOD only; DO counted double). Bairagarh is first in 5 of 6 and Prempura last in 5 of 6; ranks 3 to 6 reorder. The weighting is our judgment call.

## What works

- Full pipeline from the two CSVs to all outputs in under a second, stdlib only.
- 26 unit tests: classification of missing / BDL / ND, limit boundaries, a hand-computed score, missing data never improving a ghat, all headline numbers, the ranking, sensitivity and PDF spot-checks.
- Checked against the original PDFs with `tools/verify_pdf.py`: all **111 of 111** fully numeric DO/BOD/pH table rows found on the cited page (50 on one line in `-layout` text, 51 in the 2023 stacked layout, 10 on pages where `-layout` misplaces columns and `-raw` order was used). The **9 rows with gaps** (pages 28, 29, 59, 60) were read by eye and match the PDF text.
- Spot-checks: Bairagarh DO = 0 at 2023 Ganesh "after" (p.26) and 2023 Durga pre and during (p.60); Malikhedi 2025 Ganesh "during" DO = 0.6 (p.29, with `*`, `**` and blanks); Shahpura 2025 Durga pre DO = 2.5 (p.65).
- `report.html` tested headless (Edge) at 390 px in light and dark mode: no JS errors, no horizontal page scroll, Hindi toggle works and is remembered, Copy puts plain text (no markdown symbols) on the clipboard.

## What does not work / limits (please read)

- **The score is a screening aid, not an official index.**
- **It ranks 2023–2025 history, not today's water.** No 2026 results exist.
- **Only DO, BOD and pH are scored.** The other 10 tests are shown in the evidence but not scored.
- **The metals are not scored**: only 4 were tested (chromium, lead, zinc, copper) and Class B sets no limit for them.
- **Total coliform**, the other Class B limit, **is not in the MPPCB tables.**
- **Units are assumed.** The reports print none; the standard unit for each test is used.
- **Rani Kamlapati ghat / Kamla Park kund may be two places**: Ganesh tables say "Kamla Park kund", Durga tables say "Lower Lake ghat". It is kept as one site and flagged.
- **Several ghats sit on the Upper and Lower Lakes, where the NGT has banned immersion** (Free Press Journal, 26 Feb 2026; not checked against the order itself).
- **The Hindi text has not been proofread by a native speaker.**
- **No health claims.** The tool reports readings against limits only.
- On 2 PDF pages (2023 p.60, 2025 p.65) the text extraction scrambles columns; values there were confirmed in `-raw` reading order, where table labels print out of place, so site attribution on those pages rests on the order of the labels in the layout.
- No map, portal, or connection to any live government system, by design.
